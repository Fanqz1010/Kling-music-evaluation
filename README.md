AI音乐生成听感评测报告——基于可灵21条样本
 
摘要
 
本报告对可灵生成的21条音乐样本进行了10维度听感评测。样本覆盖影视配乐、摇滚、民谣、K-pop、古风、爵士、桑巴、交响乐等多种风格，均为10秒短音频。评测采用5分制加权评分，权重为：和声编曲15%、音色音质15%、结构15%、人声自然度10%、风格一致性10%、混音空间5%、旋律性5%、节奏5%、创意性3%、指令遵循2%（注：由于每项满分5分，总分满分为50分，表格中“总分”为各项直接相加）。
 
结果显示：21条样本总体均分为 14.43分（满分50分），整体可用率较低。其中，音色音质维度表现最好（均分2.24），人声自然度和混音空间维度表现最差（均分分别为1.33和1.33）。主要问题包括：人声机械感强、混音空间狭窄、结构完整性不足、部分风格（如摇滚、放克）的律动和音色失真明显。结论：可灵在影视配乐、民谣、古风等器乐为主的风格中表现相对较好，适合作为短视频背景音乐或灵感草稿；但在人声、复杂编曲和混音质量上存在系统性短板，暂不适合直接发行或高要求商业作品。
 
1. 评测背景与目的
背景：AI音乐生成技术快速发展，但缺乏维度化、可复现的听感评测标准。
目的：评估可灵在旋律、和声、节奏、音质、结构、人声、风格一致性等维度的表现，识别其优势与短板。
用途：为创作者选择工具提供参考、为模型方提供bad case反馈、为个人作品集积累项目经验。

4. 评测方法
每首样本听2遍，间隔重听，避免疲劳。
先整体听，再分维度打分。
尽量盲评：隐藏prompt，先听感打分，再对照prompt评“指令遵循”。
评分制：1-5分，可保留0.5分。
总分 = 各维度直接相加（满分50分）。

6.3 最佳案例

优点：音色音质较好（3分），风格一致性高（3分），混音空间有层次（2分）。

6.4 典型bad case
1.样本3：E弗里吉亚科幻配乐，总分12分。Prompt：纯音乐，E弗里吉亚科幻配乐，120BPM。合成器脉冲与低频正弦波铺底。管弦铜管奏压迫性主题，女声无词吟唱与电子脉冲形成节奏复调对位。和声基于弗里吉亚音阶，低音持续音上方平行和弦移动。
问题：人声自然度极低（1分），音色音质差（1分），结构不完整（1分），混音空间狭窄（1分）。
归因：女声无词吟唱机械感强，合成器与管弦乐融合度差，低频与高频冲突。 
2.样本18：A大调巴西桑巴，总分12分。Prompt：纯音乐，A大调巴西桑巴，130BPM，2/4拍。桑巴鼓组（Surdo、Agogo）节奏密集热烈。铜管组奏嘹亮旋律，和声进行充满张力。高潮明亮，夏日狂欢。
问题：人声自然度低（1分），音色音质差（1分），风格一致性低（1分），混音空间狭窄（1分）。
归因：桑巴节奏律动不自然，铜管音色失真，混音缺乏空间感。 


 
7. 结论与建议
对模型方：加强人声自然度、混音空间、结构规划、音色音质四个维度的优化。建议引入多人盲评机制，建立bad case库，针对性地进行模型微调。
对创作者：可灵适合生成器乐为主的影视配乐、民谣、古风等风格，可作为短视频背景音乐或灵感草稿。但不适合直接发行或高要求商业作品，尤其是人声和复杂编曲场景。
对评测流程：建立维度化、多人盲评、bad case库的评测体系。下一步可扩样本量、加入客观指标（BPM、调性、频谱分析）、引入多人评测。
下一步计划：将21条样本扩展到100条，加入客观指标分析，撰写更详细的评测报告，并发布到GitHub和知乎。
